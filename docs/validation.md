# 本地验收（发布前必做）

离线测试仅模拟接口，不代表真实 DSH 兼容。请使用独立 profile 和临时目录，勿用真实凭据、生产环境或重要数据。

1. 记录 DSH 版本；确认官方 Auto Review 已启用、插件设置可见且全部字段可编辑。
2. 验证标准模式：普通只读操作正常；用临时测试文件构造未经授权的删除请求，观察审查或人工确认，取消执行。确认拒绝理由按中文和英文用户消息分别输出，未额外调用模型。
3. 验证三档与自定义：使用相同的无害模拟任务，记录官方基线及每档输出。高风险场景只使用合成的离线快照，不执行实际敏感操作。
4. 修改详细度、专业度、易懂度与语言；确认仅理由文本变化，决策协议仍兼容。验证设置变更后生效、多行策略能够完整保存。
5. 验证错误、取消及卸载：模拟模型返回无效 JSON、取消请求；不得因错误而放行。卸载后官方审查继续工作。
6. 检查日志和模型调用次数：单次审核正常路径只派发一个 reviewer 请求；不记录上下文、密钥或自定义策略。测试其他插件兼容性前先隔离。
7. 记录实际测试证据、版本、失败项；所有关键项通过后才能发布或申请市场收录。
